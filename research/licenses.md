## Current distributed-material register

This is the release register for the current 0.45.1 edition. It records the
material that is actually shipped or generated in the repository, rather than
an obsolete historical source map. “Included” means present in the source
repository or generated deliverable; “not embedded” means used during research
or validation but not copied into the HTML/PDF.

The detailed register below uses the same fields for every source/material:
source and owner, exact material, use type, licence and authoritative licence
evidence, attribution requirement, modification-notice requirement,
redistribution conditions, final inclusion, compliance status, and notes. “N/A”
is an affirmative result: the field does not apply because the material is not
redistributed, rather than an unreviewed blank.

## Audit checks

Before release, compare this table with the distributable file list, inspect
new binary or image files, and update the relevant row if an asset or copied
excerpt is added. The current repository contains no third-party screenshots,
logos, fonts, JavaScript libraries, or long quotations. The generated jj help
captures are the only intentionally retained copy-like material and are
covered by the bundled Apache-2.0 text.

## Distribution statement

The book's original prose, diagrams, CSS, scripts, and HTML are released by this project under **CC BY 4.0**; see `research/book-license.md`. That project licence does not relicense third-party materials. The complete Apache 2.0 text is distributed in `LICENSES/Apache-2.0.txt` for the Jujutsu-derived generated help/inventory material. When redistributing the HTML, retain this ledger, the source links, and the attribution notice; provide the third-party licences when redistributing any third-party material.

The HTML contains no third-party images, bundled fonts, JavaScript libraries, copied documentation blocks, or logo artwork. External links are references, not embedded content. This design keeps the Kindle Scribe PDF output clear of additional asset licences. Distribution notices are in `THIRD_PARTY_NOTICES` and the root `LICENSE`.
